# **App Name**: Star Paths: The Future-Ready Board Game Dashboard

## Core Features:

- Board Game Dashboard: Interactive space-themed board game inspired by 'Chutes and Ladders' for navigating learning links.
- Navigable Learning Path: Vertical zig-zag track with 50 squares, each linking to a unique 'Future Ready' resource, gamifying exploration.
- Roll and Move: Interactive 'Roll Die' button generates movement, triggering boosters (rockets) and space slides (wormholes) on the board.
- Dynamic Theme: Toggleable Day/Night mode alters background: night shows twinkling stars, day reveals fluffy clouds and a pulsating sun.
- Progressive Discovery: Squares transition from red to green upon visit, tracking progress; clicking a square reveals info in a transparent sidebar.
- Interactive Mini-Map: Floating Map button offers a bird's eye view with hoverable titles, for easier pathfinding to each educational corner of the site.
- Animated Shortcuts and Slides: Booster (rockets) launch the user forward to various educational resources, and Slides bring the user down back towards Earth. This functionality will be supported by appropriate animations.

## Style Guidelines:

- Primary color: Comet-trail lavender (#CAB8FF) to inspire space travel and educational pursuit. This provides a whimsical but tech-forward feeling to guide exploration.
- Background color: Deep-space navy (#0D1B3D), offering a calm and spacious dark mode experience. Creates depth and complements the vivid design elements.
- Accent color: Rocket-flame coral (#FF8FA3) to signal interaction points, and encourage movement throughout this application. This can add vibrancy for critical calls to action such as boost prompts and board game functionality. 
- Headline font: 'Nunito Sans' bold (sans-serif) for headers and titles
- Body font: 'Nunito' regular (sans-serif) for body text
- Custom chunky, playful icons, matching the user’s directions for art styling for each board element.
- Gentle ‘whoosh’ SFX on warp, 'ding' on rocket travel and trombone-sound SFX on space slides.
